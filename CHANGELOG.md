# Changelog

## [1.0.3] — October 3, 2026

- Fixed the missing bottom gap when the Dock is on a side or set to hide itself.
- Fixed green-button clicks so they don’t send windows to full screen. The macOS tiling preview should go away once Fix Green moves the window.
- Added **Check for Updates** to the menu bar menu. It only checks when you choose it, then takes you to GitHub if a newer version is available.
- Added a reminder about refreshing Accessibility permission after an update, in case window resizing stops working.
